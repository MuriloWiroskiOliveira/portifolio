# Portfólio — Murilo Wiroski Oliveira

Portfólio pessoal desenvolvido para apresentar minha trajetória acadêmica, habilidades técnicas, projetos e evolução na área de tecnologia.

O projeto foi construído com HTML, CSS e JavaScript, utilizando um layout responsivo e uma interface voltada à apresentação profissional.

## Acesse o portfólio

**Site:** https://murilowiroskioliveira.github.io/portifolio/

**GitHub:** https://github.com/MuriloWiroskiOliveira

## Sobre o projeto

Este portfólio tem como objetivo centralizar minhas experiências de aprendizado e projetos desenvolvidos durante minha formação em Ciência da Computação.

Atualmente, curso Ciência da Computação na UniRitter e possuo formação em Análise de Dados pela EBAC. Tenho interesse em desenvolvimento de software, programação e análise de dados.

Estou em busca de oportunidades de estágio na área de tecnologia, com o objetivo de desenvolver minhas habilidades e contribuir em projetos reais.

## Funcionalidades

- Apresentação pessoal e trajetória acadêmica.
- Seção de habilidades e tecnologias estudadas.
- Exibição automática de repositórios públicos do GitHub.
- Navegação adaptada para dispositivos móveis.
- Links para contato e perfis profissionais.
- Atualização automática do ano no rodapé.

## Tecnologias utilizadas

- **HTML5:** estrutura e organização do conteúdo.
- **CSS3:** estilização, layout e responsividade.
- **JavaScript:** interatividade e funcionalidades dinâmicas.
- **GitHub REST API:** consulta aos repositórios públicos.
- **Git e GitHub:** versionamento e hospedagem do código.

## Executar localmente

1. Clone o repositório:

```bash
git clone https://github.com/MuriloWiroskiOliveira/portifolio.git
```

2. Entre na pasta:

```bash
cd portifolio
```

3. Abra o arquivo `index.html` no navegador.

Também é possível abrir o projeto no Visual Studio Code para visualizar e editar os arquivos.
